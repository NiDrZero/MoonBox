## Project Status

MoonBox is a personal project, built and maintained solo.

It is (or will be) open source, and you're welcome to read through the code,
fork it, or use it as reference or inspiration for your own projects.

This project does not accept outside contributions. That means:

- no pull requests will be reviewed or merged,
- no issues will be triaged or actioned,
- no feature requests will be tracked,
- and no support is provided.

MoonBox is shared as-is. If something breaks for you, forking and fixing it
yourself is the expected path, not filing an issue here.

This isn't a rejection of collaboration in general — it's simply that this
project exists for personal use, and keeping it solo keeps the direction
consistent and the maintenance burden sustainable.
